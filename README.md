# DBMS Lab (Semester 3)

Weekly SQL and PL/SQL exercises for the Database Management Systems lab, B.Tech CSE (FinTech), Manipal Institute of Technology. Everything was run on Oracle Database with SQL*Plus.

Each week is a Markdown file with the question, the SQL or PL/SQL, and notes. The lab manual is included as `CSF2242-DBS LabManual 2026_1.pdf`.

| Week | Topic |
| ---- | ----- |
| [1](Week1/Week1.md) | Creating tables, inserting rows and basic `SELECT` queries |
| [2](Week2/Week2.md) | Constraints, primary and foreign keys, and querying related tables |
| [3](Week3/Lab3.md) | Set operations (`UNION`, `INTERSECT`, `MINUS`) on the UNIVERSITY database |
| [4](Week4/Week4.md) | `GROUP BY`, aggregate functions and filtering groups |
| [5](Week5/Week5.md) | Joins and subqueries on a banking database |
| 6 | Not included |
| [7](Week7/Week7.md) | PL/SQL blocks: variables, conditions and loops |
| [8](Week8/Week8.md) | Cursors and cursor attributes |
| [9](Week9/Week9.md) | Stored procedures and functions |
| [10](Week10/Week10.md) | Row-level and database triggers |

## Run the examples

Start SQL*Plus, create the tables from the top of each file, then paste the queries. PL/SQL blocks need `SET SERVEROUTPUT ON` first to show output.
