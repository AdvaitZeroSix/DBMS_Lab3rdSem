# DBMS_Lab3rdSem

This repository contains the Database Management Systems (DBMS) laboratory work for Semester 3 of the BTech CSE (FinTech) program at Manipal Institute of Technology.

The repository includes the DBMS lab manual and weekly SQL exercises completed using Oracle SQL Plus.

## Contents

* `Manual.md` — DBMS laboratory manual
* `Week1/` — Basic SQL operations and table manipulation
* `Week2/` — SQL constraints, relationships, queries, functions and date operations
* `Week3/` — Integrity constraints and related SQL exercises
* `Week4/` — Advanced SQL queries, grouping, aggregate functions and transaction control

## Tools Used

* Oracle Database
* Oracle SQL Plus
* SQL
